# Chap. 03. 결제 메뉴 찾아가기

콘솔의 **"시작하기"** 화면까지 들어왔습니다. 이제 돈과 관련된 **결제(Billing)** 메뉴로 가야 합니다.
결제 메뉴로 가는 길은 두 가지입니다. **방법 1**을 먼저 해보고, 화면에 결제 단추가 안 보이면 **방법 2**를 쓰세요.

---

## 방법 1. "빠른 액세스"에서 바로 누르기 (쉬운 길)

"시작하기" 화면을 아래로 조금 내리면 **"빠른 액세스"** 라는 칸들이 보입니다.
그중 **`결제`** 라고 적힌 네모 칸을 눌러주세요.

```{figure} ../images/session2_deleteGcpCard/07.selectPayment.png
:width: 100%
:align: center
:name: s2-fig-payment

"빠른 액세스" 칸들 중 **결제**를 누릅니다.
```

```{admonition} 화면 위쪽 "작업 중인 프로젝트" 이름을 확인하세요
:class: tip
화면 위쪽에 **"작업 중인 프로젝트: ○○○"** 이라고 적혀 있습니다. 이게 바로 지금 우리가 정리하려는 작업방(프로젝트)의 이름입니다. 이름을 기억해 두면 다음 단계에서 헷갈리지 않습니다.
```

여기서 **`결제`** 단추가 잘 보였다면 → 바로 **다음 페이지(결제 계정 폐쇄)** 로 넘어가세요.
**`결제`** 단추가 안 보인다면 → 아래 **방법 2**를 따라 하세요.

---

## 방법 2. 왼쪽 메뉴에서 찾기 (결제 단추가 안 보일 때)

화면에 결제 단추가 없을 때는, **숨어 있는 전체 메뉴**를 열어서 찾으면 됩니다.

### ① 왼쪽 맨 위 "줄 세 개(☰)" 단추 누르기

화면 **왼쪽 맨 위 구석**에 **줄이 세 개 그어진 작은 단추(☰)** 가 있습니다. 이것을 누르면 숨어 있던 메뉴가 옆에서 나옵니다.

```{figure} ../images/session2_deleteGcpCard/07_1.selectPayment_otherway_01.png
:width: 100%
:align: center
:name: s2-fig-payment-alt1

왼쪽 맨 위의 **줄 세 개(☰)** 단추를 누릅니다.
```

```{admonition} 이 단추를 흔히 "햄버거 메뉴"라고 불러요
:class: note
줄 세 개가 햄버거 빵처럼 생겼다고 해서 붙은 별명입니다. 인터넷의 많은 화면에서 **이 모양은 "전체 메뉴 열기"** 를 뜻합니다. 기억해 두면 다른 곳에서도 유용합니다.
```

### ② 옆에서 나온 메뉴에서 "결제" 누르기

단추를 누르면 왼쪽에서 긴 메뉴 목록이 나옵니다.
그 목록에서 **`결제`** 를 찾아 눌러주세요.

```{figure} ../images/session2_deleteGcpCard/07_2.selectPayment_otherway_02.png
:width: 100%
:align: center
:name: s2-fig-payment-alt2

옆에서 펼쳐진 메뉴 목록에서 **결제**를 누릅니다.
```

```{admonition} 목록이 길어요. 천천히 찾으세요
:class: tip
메뉴 목록이 꽤 깁니다. 위에서부터 천천히 읽어 내려가다 보면 **`결제`** 라는 글자가 보입니다. 마우스 휠을 굴리거나 목록을 아래로 내려서 찾을 수도 있습니다.
```

---

어느 방법이든 **`결제`** 를 누르면 결제 관리 화면으로 들어갑니다.

이제 본격적으로 **1단계: 결제 계정 폐쇄**를 해봅시다. 다음 페이지로 넘어가세요.
