# Chap. 06. 카드 삭제하기

```{admonition} 지금 무엇을 하나요?
:class: important
**"카드 삭제"** 는 구글 클라우드에 등록해 둔 **신용카드를 빼내는** 일입니다.
세 가지 정리 작업 중 **마지막 세 번째**입니다. 이걸 해야 "내 카드가 구글에 등록돼 있다"는 상태가 완전히 사라집니다.
```

---

## ① 왼쪽 메뉴에서 "결제 수단" 누르기

화면 **왼쪽 메뉴 목록**에서 **`결제 수단`** 을 찾아 누릅니다.
그러면 등록된 카드(예: 신한 VISA)가 나옵니다.
카드 칸 안의 오른쪽 아래에 있는 **`삭제`** 라는 글자를 눌러주세요.

```{figure} ../images/session2_deleteGcpCard/14.deleteCard_01.png
:width: 100%
:align: center
:name: s2-fig-deletecard1

왼쪽 메뉴에서 **결제 수단**을 누른 뒤, 카드 칸의 **삭제**를 누릅니다.
```

```{admonition} "결제 수단"이 안 보이면 아래로 내려보세요
:class: tip
왼쪽 메뉴가 길어서 **결제 수단**이 화면 밖에 있을 수 있습니다. 마우스 휠을 굴려 왼쪽 메뉴를 아래로 내리면 **`결제 수단`** 글자가 나타납니다.
```

---

## ② 확인 창에서 "삭제" 한 번 더 누르기

"결제 수단을 삭제하시겠습니까?" 라는 확인 창이 뜹니다.
지울 카드 정보가 맞는지 확인한 뒤, 오른쪽 아래 파란색 **`삭제`** 단추를 한 번 더 눌러주세요.

```{figure} ../images/session2_deleteGcpCard/15.deleteCard_02.png
:width: 100%
:align: center
:name: s2-fig-deletecard2

확인 창에서 오른쪽 아래 파란색 **삭제** 단추를 누릅니다.
```

```{admonition} 확인 창 내용 요약
:class: warning
- 카드를 삭제하면, 다시 등록하기 전까지는 이 카드로 구글 서비스 결제를 할 수 없습니다. (우리가 원하는 상태입니다.)
- 아직 정산 안 된 금액이 있다면 **최대 60일까지** 이 카드에 표시될 수 있습니다. 이건 정상입니다.
```

---

## ③ 카드 삭제 완료 확인하기

삭제가 끝나면 화면에 **"결제 수단이 아직 없으신가요?"** 라는 문구와 탁구 치는 그림이 나옵니다.
등록된 카드가 하나도 없다는 뜻이니, 이 화면이 보이면 **3단계(카드 삭제) 완료**입니다.

```{figure} ../images/session2_deleteGcpCard/16.afterDelete.png
:width: 100%
:align: center
:name: s2-fig-afterdelete

**"결제 수단이 아직 없으신가요?"** 화면이 보이면 카드가 모두 삭제된 것입니다.
```

---

## 🎉 모든 정리가 끝났습니다!

축하합니다. 세 가지 작업을 모두 마쳤습니다.

- ✅ 1단계: 결제 계정 폐쇄
- ✅ 2단계: 프로젝트 결제 사용 중지
- ✅ 3단계: 카드 삭제

이제 구글 클라우드에서 **더 이상 새로운 요금이 청구되지 않으며, 등록된 카드도 모두 빠진 상태**입니다.

혹시 궁금한 점이나 불안한 점이 있다면 **다음 페이지(자주 묻는 질문)** 를 꼭 읽어보세요.
