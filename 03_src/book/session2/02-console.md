# Chap. 02. 클라우드 콘솔 들어가기

로그인을 마쳤으면, 이제 구글 클라우드를 관리하는 화면인 **"콘솔(Console)"** 로 들어가야 합니다.
콘솔은 **내 클라우드 설정을 바꾸는 관리 사무실** 같은 곳이라고 생각하시면 됩니다. 결제를 멈추는 일도 여기서 합니다.

---

## ① 구글에서 "gcp console" 검색하기

구글 첫 화면 가운데의 **검색 칸**에 **`gcp console`** 이라고 입력합니다.
(`gcp`는 구글 클라우드의 약자이고, `console`은 관리 화면이라는 뜻입니다.)

```{figure} ../images/session2_deleteGcpCard/04.search.png
:width: 100%
:align: center
:name: s2-fig-search

검색 칸에 `gcp console` 이라고 입력합니다. 입력 후 키보드의 **엔터(Enter)** 를 누르세요.
```

```{admonition} 글자를 입력하면 아래에 여러 줄이 떠요
:class: note
검색 칸에 글자를 치면 그 아래로 추천 단어들이 주르륵 나타납니다. 신경 쓰지 말고 **`gcp console`** 까지만 입력한 뒤 키보드의 **엔터** 키를 누르면 됩니다.
```

---

## ② 검색 결과에서 "Google Cloud console" 누르기

검색 결과 화면이 나오면, **`Google Cloud console`** 이라고 적힌 파란색 글씨(링크)를 눌러주세요.

```{figure} ../images/session2_deleteGcpCard/05.selectSite.png
:width: 100%
:align: center
:name: s2-fig-selectsite

검색 결과 중 **Google Cloud console** 이라는 파란 글씨를 누릅니다.
```

```{admonition} 주소가 cloud.google.com 인지 확인하세요
:class: tip
누르려는 링크 위에 작은 글씨로 **`https://cloud.google.com`** 이라고 적혀 있으면 올바른 곳입니다. 가끔 위쪽에 "광고"라고 표시될 수 있는데, 주소만 맞다면 눌러도 괜찮습니다.
```

---

## ③ 구글 클라우드 화면에서 "콘솔" 누르기

구글 클라우드 소개 페이지가 열리면, **화면 오른쪽 맨 위**에 **`콘솔`** 이라는 글자가 있습니다. 그것을 눌러주세요.

```{figure} ../images/session2_deleteGcpCard/06.selectConsole.png
:width: 100%
:align: center
:name: s2-fig-console

구글 클라우드 소개 페이지. 오른쪽 위의 **콘솔**을 누릅니다.
```

```{admonition} 화면 가운데 큰 글씨에 현혹되지 마세요
:class: note
가운데에 "에이전트 AI의 시대..." 같은 광고성 큰 글씨와 파란 단추들이 보일 수 있는데, 우리가 누를 것은 **오른쪽 위 구석의 작은 `콘솔` 글자**입니다.
```

---

콘솔에 들어가면 **"시작하기"** 라는 화면이 나옵니다. 여기까지 오셨다면 절반은 성공입니다!
