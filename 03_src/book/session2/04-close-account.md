# Chap. 04. 결제 계정 폐쇄하기

```{admonition} 지금 무엇을 하나요?
:class: important
**"결제 계정 폐쇄"** 는 돈을 내는 **"통장 묶음" 자체를 닫는** 일입니다.
세 가지 정리 작업 중 **첫 번째**입니다.
```

---

## ① "결제 계정 관리" 누르기

결제 메뉴에 들어오면 **"개요"** 화면이 보입니다.
화면 위쪽 가운데에 톱니바퀴 모양과 함께 **`결제 계정 관리`** 라는 글자가 있습니다. 그것을 눌러주세요.

```{figure} ../images/session2_deleteGcpCard/08.editAccount.png
:width: 100%
:align: center
:name: s2-fig-editaccount

결제 개요 화면. 위쪽의 **결제 계정 관리**를 누릅니다.
```

```{admonition} 화면에 0원이 보여도 정상입니다
:class: note
"총비용 $0.00" 처럼 0원으로 보일 수 있습니다. 지금까지 쓴 돈이 없다는 뜻이니 안심하세요. 우리는 앞으로도 돈이 안 나가게 정리하는 중입니다.
```

---

## ② "결제 계정 폐쇄" 누르기

"계정 관리" 화면이 나오면, 위쪽에 **`결제 계정 폐쇄`** 라는 글자가 있습니다. 그것을 눌러주세요.

```{figure} ../images/session2_deleteGcpCard/09.closeAccount_01.png
:width: 100%
:align: center
:name: s2-fig-close1

계정 관리 화면 위쪽의 **결제 계정 폐쇄**를 누릅니다.
```

---

## ③ 안내문 읽고, "폐쇄"라고 입력한 뒤 확정하기

그러면 긴 안내문이 담긴 창이 뜹니다. 천천히 읽어보셔도 좋고, 핵심은 아래에 정리해 두었습니다.

이 창의 **맨 아래쪽 입력 칸**에 한글로 **`폐쇄`** 라고 직접 입력한 다음, 오른쪽 아래 파란색 **`결제 계정 폐쇄`** 단추를 눌러주세요.

```{figure} ../images/session2_deleteGcpCard/10.closeAccount_02.png
:width: 70%
:align: center
:name: s2-fig-close2

아래 칸에 **폐쇄**라고 입력하고, 오른쪽 아래 **결제 계정 폐쇄** 단추를 누릅니다.
```

```{admonition} 왜 "폐쇄"라고 직접 입력하게 하나요?
:class: note
실수로 누르는 것을 막기 위한 **마지막 확인 절차**입니다. 정말 닫을 생각이 맞는지 사람이 직접 글자를 적게 해서, 한 번 더 확인하는 것입니다.
```

```{admonition} 안내문의 핵심만 요약하면
:class: warning
- 계정을 닫으면 연결된 작업(VM 등)이 **모두 멈춥니다.**
- 지금까지 쓴 요금이 있다면 **최대 48시간 안에 정산**될 수 있습니다. (0원이면 나갈 돈도 없습니다.)
- 남은 선불 크레딧이 있으면 환불을 요청할 수 있습니다.
```

---

## ④ 폐쇄 완료 확인하기

성공하면 화면 위쪽에 **빨간색 띠**로 **"해지된 결제 계정입니다"** 라는 문구가 나타납니다.
이 빨간 띠가 보이면 **1단계(결제 계정 폐쇄) 완료**입니다.

```{figure} ../images/session2_deleteGcpCard/11.afterClose.png
:width: 100%
:align: center
:name: s2-fig-afterclose

위쪽에 빨간 띠로 **"해지된 결제 계정입니다"** 가 보이면 성공입니다.
```

```{admonition} 실수로 닫았어도 되돌릴 수 있어요
:class: tip
빨간 띠 위쪽을 보면 **"결제 계정 다시 개설"** 이라는 글자가 있습니다. 혹시 잘못 닫았더라도 이것을 누르면 다시 열 수 있으니 너무 걱정하지 마세요.
```
