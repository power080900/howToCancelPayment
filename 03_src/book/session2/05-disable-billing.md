# Chap. 05. 프로젝트 결제 사용 중지하기

```{admonition} 지금 무엇을 하나요?
:class: important
**"프로젝트 결제 사용 중지"** 는 내가 만든 **작업방(프로젝트)에 돈이 연결되는 길을 끊는** 일입니다.
세 가지 정리 작업 중 **두 번째**입니다.
```

```{admonition} 결제 계정 폐쇄랑 뭐가 다른가요?
:class: note
- **1단계(계정 폐쇄)** 는 "돈 내는 통장 묶음"을 닫는 것이고,
- **2단계(사용 중지)** 는 "내 작업방과 그 통장의 연결선"을 끊는 것입니다.

둘 다 해주면, 작업방과 결제가 확실하게 분리되어 더 안전합니다.
```

---

## ① 프로젝트 옆 "점 세 개(⋮)" 누르기

방금 그 계정 관리 화면 아래쪽을 보면 **"이 결제 계정에 연결된 프로젝트"** 라는 목록이 있습니다.
내 프로젝트 줄의 오른쪽, **작업(⋮)** 칸에 있는 **세로 점 세 개(⋮)** 를 누릅니다.
그러면 작은 메뉴가 펼쳐지는데, 맨 위 **`결제 사용 중지`** 를 눌러주세요.

```{figure} ../images/session2_deleteGcpCard/12.detachProject_01.png
:width: 100%
:align: center
:name: s2-fig-detach1

프로젝트 줄 오른쪽의 **점 세 개(⋮)** 를 누른 뒤, **결제 사용 중지**를 누릅니다.
```

```{admonition} "점 세 개" 모양은 "더 많은 기능"이라는 뜻이에요
:class: tip
세로로 찍힌 점 세 개(⋮)는 인터넷 화면에서 **"여기 숨은 기능이 더 있어요"** 를 의미합니다. 눌러야 메뉴가 나타나니, 안 보인다고 당황하지 마세요.
```

---

## ② 확인 창에서 "결제 사용 중지" 한 번 더 누르기

"결제를 사용 중지하시겠어요?" 라는 확인 창이 뜹니다.
내용을 확인한 뒤, 오른쪽 아래 **`결제 사용 중지`** 를 한 번 더 눌러주세요.

```{figure} ../images/session2_deleteGcpCard/13.detachProject_02.png
:width: 100%
:align: center
:name: s2-fig-detach2

확인 창에서 오른쪽 아래 **결제 사용 중지**를 누릅니다.
```

```{admonition} 확인 창 내용 요약
:class: warning
- 결제를 사용 중지하면 그 작업방의 **서비스가 멈출 수 있습니다.**
- 아직 청구되지 않은 **오늘까지의 요금**은 연결된 계정으로 청구됩니다. (쓴 게 없으면 0원입니다.)
```

---

다 누르면 화면 아래쪽에 **"○○○ 프로젝트의 결제가 사용 중지되었습니다"** 라는 검은색 알림이 잠깐 나타납니다.
이 알림이 보이면 **2단계(프로젝트 결제 사용 중지) 완료**입니다.

이제 마지막, **3단계: 카드 삭제**만 남았습니다. 다음 페이지로 넘어가세요.
