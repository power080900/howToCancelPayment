# Chap. 01. OpenAI 사이트 찾아 로그인하기

```{admonition} 이번 세션은 무엇을 하나요?
:class: important
**OpenAI** 는 챗GPT를 만든 회사입니다. 여기에도 **"API 키"** 라는 것과 **결제 카드**를 등록해 두었다면, 정리하지 않을 경우 요금이 나갈 수 있습니다.
이번 세션에서는 OpenAI에 등록한 **① API 키를 삭제**하고 **② 카드를 빼내는** 두 가지를 합니다.
```

```{admonition} "API 키"가 뭔가요?
:class: note
**API 키**는 프로그램이 OpenAI 기능(챗GPT 등)을 가져다 쓸 때 내미는 **비밀 열쇠**입니다.
이 열쇠가 살아 있으면, 그 열쇠를 쓰는 프로그램이 작동할 때마다 **요금이 나갈 수 있습니다.** 그래서 더 이상 쓰지 않는다면 열쇠를 **삭제**하는 것이 안전합니다.
```

---

## ① 구글에서 "openai" 검색하기

인터넷 창(크롬, 엣지 등)을 열고, 구글 검색 칸에 **`openai`** 라고 입력한 뒤 키보드의 **엔터(Enter)** 를 누릅니다.

```{figure} ../images/session3_openAI/01.search.png
:width: 100%
:align: center
:name: s3-fig-search

구글 검색 칸에 `openai` 라고 입력하고 엔터를 누릅니다.
```

---

## ② 검색 결과에서 "OpenAI" 누르기

검색 결과에서 **`OpenAI`** 라고 적힌 파란 글씨(공식 사이트 링크)를 눌러주세요.

```{figure} ../images/session3_openAI/02.clickOpenAI.png
:width: 100%
:align: center
:name: s3-fig-clickopenai

검색 결과 중 **OpenAI** 공식 사이트를 누릅니다.
```

```{admonition} 주소가 openai.com 인지 확인하세요
:class: tip
링크 위에 작은 글씨로 **`https://openai.com`** 이라고 적혀 있으면 올바른 곳입니다. 비슷해 보이는 다른 주소는 누르지 마세요.
```

---

## ③ "OpenAI Platform(플랫폼)"으로 들어가기

OpenAI 화면에서 **`Platform`**(플랫폼) 또는 **`Log in`(로그인)** 을 눌러, 결제·API 키를 관리하는 **개발자용 페이지(platform.openai.com)** 로 들어갑니다.

```{figure} ../images/session3_openAI/03.clickOpenAIplatform.png
:width: 100%
:align: center
:name: s3-fig-platform

**Platform**(플랫폼)을 눌러 관리 페이지로 들어갑니다.
```

```{admonition} 일반 챗GPT 화면과는 다른 곳이에요
:class: note
우리가 갈 곳은 채팅하는 화면이 아니라, **API 키와 결제를 관리하는 페이지**입니다. 주소 칸에 **`platform.openai.com`** 이 보이면 제대로 온 것입니다.
```

---

## ④ 내 계정으로 로그인하기

**`Log in`(로그인)** 을 누른 뒤, OpenAI에 가입할 때 쓴 **이메일과 비밀번호**(또는 "구글로 계속하기")로 로그인합니다.

```{figure} ../images/session3_openAI/04.login.png
:width: 100%
:align: center
:name: s3-fig-login

가입할 때 쓴 방법으로 로그인합니다.
```

```{admonition} "Continue with Google"이 편해요
:class: tip
가입할 때 구글 계정으로 가입했다면, **`Continue with Google`(구글로 계속하기)** 을 누르고 내 구글 계정을 고르면 비밀번호 없이 빠르게 로그인됩니다.
```

---

로그인이 끝나면 관리 페이지로 들어옵니다. 다음 페이지에서 먼저 **API 키를 삭제**해 봅시다.
