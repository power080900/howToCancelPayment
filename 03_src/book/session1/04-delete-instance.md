# Chap. 04. VM 인스턴스(가상 컴퓨터) 삭제하기

```{admonition} 지금 무엇을 하나요?
:class: important
목록에서 더 이상 쓰지 않는 **가상 컴퓨터를 골라 완전히 삭제**합니다.
삭제하면 그 컴퓨터에서 나가던 **요금이 멈춥니다.**
```

```{admonition} 삭제하기 전에 꼭 확인하세요
:class: warning
**삭제한 가상 컴퓨터와 그 안의 자료는 되돌릴 수 없습니다.** 안에 보관해 둔 중요한 파일이 없는지 먼저 확인하세요. (실습용으로 만든 것이거나, 안에 중요한 게 없다면 그냥 삭제해도 됩니다.)
```

---

## ① 삭제할 컴퓨터를 고르고 "삭제" 누르기

목록에서 삭제할 가상 컴퓨터 줄의 **왼쪽 네모 칸(체크박스)** 을 눌러 체크합니다.
그런 다음 화면 **위쪽**에 나타나는 **`삭제`**(휴지통 모양) 단추를 눌러주세요.

```{figure} ../images/session1_deleteVmEngine/09.deleteInstance_01.png
:width: 100%
:align: center
:name: s1-fig-delinstance1

삭제할 컴퓨터를 체크한 뒤, 위쪽의 **삭제** 단추를 누릅니다.
```

```{admonition} 줄 하나를 통째로 고르는 방법
:class: tip
줄 맨 왼쪽의 작은 **네모 칸**을 누르면 그 줄에 파란 표시가 생깁니다. "이 컴퓨터를 고르겠다"는 뜻입니다. 여러 대를 한꺼번에 고를 수도 있습니다.
```

---

## ② 확인 창에서 "삭제" 한 번 더 누르기

"인스턴스를 삭제하시겠습니까?" 라는 확인 창이 뜹니다.
지울 컴퓨터가 맞는지 확인한 뒤, 오른쪽 아래 파란색 **`삭제`** 단추를 한 번 더 눌러주세요.

```{figure} ../images/session1_deleteVmEngine/10.deleteInstance_02.png
:width: 70%
:align: center
:name: s1-fig-delinstance2

확인 창에서 오른쪽 아래 **삭제** 단추를 누릅니다.
```

```{admonition} 한 번 더 묻는 건 안전장치예요
:class: note
중요한 작업이라 **"정말 지울 건가요?"** 라고 한 번 더 확인하는 것입니다. 실수로 지우는 것을 막아주는 정상적인 절차입니다.
```

---

## ③ 삭제 완료 확인하기

삭제가 끝나면 목록에서 그 컴퓨터가 사라집니다.
지운 컴퓨터가 더 이상 보이지 않으면 **삭제 완료**입니다. 이제 그 컴퓨터에서 나가던 요금도 멈춥니다.

```{figure} ../images/session1_deleteVmEngine/11.afterDelete.png
:width: 100%
:align: center
:name: s1-fig-afterdelete

삭제한 컴퓨터가 목록에서 사라졌습니다. 요금도 함께 멈춥니다.
```

축하합니다. 돈이 나가던 **가상 컴퓨터(VM 인스턴스)를 삭제**했습니다.

