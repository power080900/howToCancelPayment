# Chap. 01. 구글에 로그인하기

가장 먼저, 내 구글 계정으로 **로그인(나임을 확인하고 들어가는 것)** 을 해야 합니다.
컴퓨터에서 인터넷 창(크롬, 엣지 등)을 열고, 주소 칸에 **google.com** 이라고 입력해 구글 첫 화면을 띄워주세요.

---

## ① 오른쪽 위 "로그인" 누르기

구글 첫 화면이 나오면, **화면 오른쪽 맨 위 구석**에 파란색 **`로그인`** 단추가 있습니다. 빨간 네모 칸 안에 있는 그 단추를 눌러주세요.

```{figure} ../images/session1_deleteVmEngine/01.main.png
:width: 100%
:align: center
:name: s1-fig-main

구글 첫 화면. 오른쪽 위 파란색 **로그인** 단추를 누릅니다.
```

```{admonition} 이미 로그인 되어 있다면?
:class: tip
오른쪽 위에 **로그인 단추 대신 동그란 사진(또는 색깔 동그라미)** 이 보인다면, 이미 로그인된 상태입니다. 이 경우 이 단계는 건너뛰고 **다음 페이지(콘솔 들어가기)** 로 넘어가도 됩니다.
```

---

## ② 내 계정 고르기

로그인 단추를 누르면 **"계정을 선택하세요"** 라는 화면이 나옵니다.
여기서 **내 이름(내 구글 계정)** 이 적힌 줄을 눌러주세요.

```{figure} ../images/session1_deleteVmEngine/02.login.png
:width: 100%
:align: center
:name: s1-fig-account

"계정을 선택하세요" 화면. 내 이름이 적힌 칸을 누릅니다.
```

```{admonition} 내 계정이 목록에 안 보이면?
:class: note
아래쪽의 **"다른 계정 사용"** 을 누른 다음, 가입할 때 썼던 **이메일 주소**를 직접 입력하면 됩니다.
```

---

## ③ 비밀번호 입력하기

계정을 고르면 **비밀번호를 입력하는 칸**이 나옵니다.
가운데 칸에 내 구글 계정 **비밀번호**를 입력하고, 오른쪽 아래 파란색 **`다음`** 단추를 누릅니다.

```{figure} ../images/session1_deleteVmEngine/03.password.png
:width: 100%
:align: center
:name: s1-fig-password

비밀번호를 입력하는 화면. 입력한 뒤 오른쪽 아래 **다음**을 누릅니다.
```

```{admonition} 입력한 비밀번호가 맞는지 확인하고 싶다면
:class: tip
비밀번호 칸 아래의 **"비밀번호 표시"** 라는 네모 칸을 누르면, 가려져 있던 비밀번호 글자가 보입니다. 오타가 없는지 눈으로 확인할 수 있어요.
```

```{admonition} 휴대전화로 본인 확인 문자가 올 수 있어요
:class: warning
비밀번호를 맞게 넣어도, 안전을 위해 **휴대전화로 숫자 코드(인증번호)** 가 올 수 있습니다. 이때는 문자로 받은 숫자를 화면에 그대로 입력하면 됩니다. 이 화면은 사람마다 나올 수도, 안 나올 수도 있습니다.
```

---

로그인이 끝나면 다시 구글 첫 화면으로 돌아오는데, 이번엔 오른쪽 위에 **내 계정 동그라미**가 보일 거예요. 그러면 로그인 성공입니다.
