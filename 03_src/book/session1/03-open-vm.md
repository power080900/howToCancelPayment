# Chap. 03. VM 엔진(가상 컴퓨터) 화면 열기

```{admonition} 지금 무엇을 하나요?
:class: important
**VM(가상 컴퓨터)** 은 구글 클라우드에서 빌려 쓰는 **인터넷 속 컴퓨터 한 대**입니다.
이 컴퓨터는 **켜져 있는 동안 계속 돈이 나갑니다.** 그래서 더 이상 쓰지 않는다면 **삭제**해서 요금을 멈춰야 합니다.
이번 단계에서는 그 가상 컴퓨터들이 모여 있는 **"VM 엔진(Compute Engine)"** 화면으로 들어갑니다.
```

```{admonition} 아주 쉬운 비유
:class: note
VM은 **시간제로 빌린 방**과 같습니다. 방을 비워도 **"빌린 상태"로 두면 방값(요금)이 계속 나갑니다.** 방을 완전히 **반납(삭제)** 해야 돈이 멈춥니다.
```

---

## ① 콘솔에서 "Compute Engine(VM 엔진)" 찾아 들어가기

콘솔 화면 **왼쪽 맨 위 줄 세 개(☰)** 단추를 누르면 전체 메뉴가 펼쳐집니다.
그 목록에서 **`Compute Engine`**(컴퓨트 엔진, = VM 엔진)을 찾아 누른 뒤, 이어 나오는 **`VM 인스턴스`** 를 눌러주세요.

```{figure} ../images/session1_deleteVmEngine/07.selectVmEngine.png
:width: 100%
:align: center
:name: s1-fig-vmengine

전체 메뉴에서 **Compute Engine** 을 찾아 누릅니다. (= 가상 컴퓨터를 관리하는 메뉴)
```

```{admonition} "Compute Engine"이라는 영어가 어렵게 느껴진다면
:class: tip
`Compute Engine`(컴퓨트 엔진)은 **"가상 컴퓨터를 빌려주는 곳"** 이라는 뜻의 메뉴 이름입니다. 글자 모양만 기억해서 같은 글자를 찾아 누르면 됩니다. 메뉴가 길면 마우스 휠을 굴려 아래로 내려보세요.
```

---

## ② "VM 인스턴스" 목록 화면 확인하기

`VM 인스턴스` 를 누르면, 내가 빌려 둔 **가상 컴퓨터들의 목록**이 나옵니다.
목록의 각 줄이 컴퓨터 한 대이며, 이름 옆에 초록색 동그라미가 있으면 **켜져서 돈이 나가는 중**이라는 뜻입니다.

```{figure} ../images/session1_deleteVmEngine/08.selectVmInstance.png
:width: 100%
:align: center
:name: s1-fig-vminstance

**VM 인스턴스** 목록 화면. 각 줄이 가상 컴퓨터 한 대입니다.
```

```{admonition} 목록이 비어 있다면?
:class: note
"인스턴스가 없습니다" 처럼 목록이 비어 있다면, 이미 삭제할 가상 컴퓨터가 없는 상태입니다. 이 경우 이 세션은 건너뛰어도 됩니다.
```

---

목록에서 삭제할 가상 컴퓨터를 확인했다면, 다음 페이지에서 **실제로 삭제**해 봅시다.
